# 以 AI 为杠杆的供应商质量管理实践 · 互动演示稿

方寸 FANGCUN 制作 · 透明玻璃风 · 1920×1080 固定舞台（整体等比缩放，手机不重排）

## 启动方式

需要通过本地 HTTP 服务打开（不能双击 file:// 打开，粒子序章和字体需要 http）：

```powershell
cd decks\ouyang-probation
python -m http.server 8932
# 浏览器打开 http://127.0.0.1:8932/index.html
```

## 操作方式

| 操作 | 效果 |
|---|---|
| 单击 / 空格 / → / PageDown / 滚轮 | 推进逐项内容，然后翻页 |
| ← / PageUp | 上一页 |
| Home / End | 封面 / 末页 |
| 序章粒子 | 点击散开 → 等文字重组 → 再点一次进入；空格跳过 |
| 游戏页 / 带教四步 / 判定卡 | 控件区点击不翻页 |
